## 🎯 Público-alvo
**Iniciantes absolutos em programação.** Pessoas que nunca escreveram uma linha de código. O material precisa ser:
- Acolhedor (sem jargão técnico solto)
- Visual (vence o "medo da tela preta")
- Lúdico (gamificação leve, BugZilla, quizzes)
- Confiante ("você vai conseguir")

## 🛠️ Stack do bootcamp (o que o aluno vai aprender)
- **Python 3** — linguagem
- **PyCharm** — IDE recomendada
- **JSON** — primeiro formato de persistência
- **TinyDB** — primeiro "banco de dados"
- **Streamlit** — primeira interface gráfica

## 📦 Stack deste projeto (o que a IA usa para construir o material)
- **HTML5 + CSS3 vanilla** — sem build, sem npm
- **JS vanilla** — toggler, scroll-reveal, sidebar
- **Google Fonts**: Nunito (texto), JetBrains Mono (código), Caveat (manuscrito conceitual)
- **Sem frameworks** — performance e simplicidade. Cada HTML abre direto no browser.

## 🎯 Objetivos pedagógicos do bootcamp
Ao final, o aluno consegue:
1. Escrever programas Python com input/output
2. Tomar decisões com `if/elif/else`
3. Repetir ações com `while` e `for`
4. Organizar dados em listas e dicionários
5. Modularizar código em funções
6. Persistir dados em arquivos JSON
7. Usar TinyDB como mini banco
8. Criar uma UI com Streamlit

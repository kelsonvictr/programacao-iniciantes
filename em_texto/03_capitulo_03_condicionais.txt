═══════════════════════════════════════════════════════ 2. O COMANDO IF ═══════════════════════════════════════════════════════

🎯

O comando `if`

Se a condição for verdadeira, execute

O garçom verificando o pedido

Imagina um garçom 🧑‍🍳 anotando seu pedido. Antes de mandar pra cozinha, ele pensa: "SE o cliente é maior de idade, posso colocar a cerveja no pedido."

═══════════════════════════════════════════════════════ 4. ELIF — MÚLTIPLOS CAMINHOS ═══════════════════════════════════════════════════════

🛤️

O comando `elif` — múltiplos caminhos

"else if" — quando você tem mais de duas opções

O cardápio do restaurante 🍽️

O garçom pergunta: "O que vai querer?" e você tem várias opções: pizza, lasanha, salada, hambúrguer… Não dá pra resolver com if/else — só dá conta de duas escolhas. Aí entra o `elif`: "else if" — se não for o anterior, será que é esse?

🚦 O semáforo (analogia favorita)

Três cores, três comportamentos. Decisão clássica de elif:

cor == "vermelho" → pare

cor == "amarelo" → atenção

cor == "verde" → siga

semaforo.py Python

```
cor = input("Cor do sinal: ")

if cor == "verde":
    print("🟢 Pode seguir!")
elif cor == "amarelo":
    print("🟡 Atenção, vai fechar!")
elif cor == "vermelho":
    print("🔴 Pare!")
else:
    print("🤔 Cor desconhecida...")
```

🚶
Bonequinho num cruzamento: ele chega, olha o sinal, e segue UM caminho. O Python testa de cima pra baixo — assim que uma condição der True, ele executa aquele bloco e ignora todos os outros.

⚠️
Só pode existir um `if` e um `else` numa mesma estrutura, mas quantos `elif` você quiser no meio.

═══════════════════════════════════════════════════════ 5. OPERADORES DE COMPARAÇÃO ═══════════════════════════════════════════════════════

⚖️

Operadores de comparação

Os símbolos que perguntam coisas

Toda condição que você coloca dentro de um `if` usa um operador de comparação. São 6 — e você já viu alguns. Bora oficializar:

==

igual a

`3 == 3` → True   `3 == 4` → False

!=

diferente de

`3 != 4` → True   `3 != 3` → False

>

maior que

`5 > 3` → True   `3 > 5` → False

<

menor que

`3 < 5` → True   `5 < 3` → False

>=

maior ou igual a

`3 >= 3` → True   `2 >= 3` → False

<=

menor ou igual a

`3 <= 3` → True   `4 <= 3` → False

🤯
Atenção máxima: `=` (uma igualdade) é atribuição (eu coloco um valor numa variável). `==` (duas) é comparação (eu pergunto se são iguais). Esse erro é tão comum que o BugZilla vai aparecer em breve só por causa dele 🐛.

═══════════════════════════════════════════════════════ 6. OPERADORES LÓGICOS ═══════════════════════════════════════════════════════

🔗

Operadores lógicos: `and`, `or`, `not`

Combinando condições

E se a condição for composta? Ex.: "se for sexta E der pra sair cedo, bora pra praia 🏖️". A gente combina condições com 3 palavrinhas:

and

e — os dois precisam ser verdadeiros
`idade >= 18 and tem_ingresso`

or

ou — basta um ser verdadeiro
`dia == "sab" or dia == "dom"`

not

negação — inverte verdadeiro/falso
`not chovendo`

acesso_clube.py Python

```
idade        = 20
tem_convite  = True

if idade >= 18 and tem_convite:
    print("Bem-vindo(a) ao clube! 🎉")
else:
    print("Acesso negado 🚫")
```

💡
Dica de ouro: imagine o `and` como dois cadeados — os dois precisam abrir. O `or` é uma porta com duas chaves — qualquer uma serve. O `not` é o avesso (vira do lado contrário).

═══════════════════════════════════════════════════════ 11. BUGZILLA 🐛 ═══════════════════════════════════════════════════════

🐛

BugZilla apareceu de novo!

Os erros clássicos do if/else

🐛

"Mas eu jurava que tava certo!"

Os tropeços mais comuns com condicionais

Tem 2 erros que todo mundo comete na primeira vez com if/else. Bora desmistificar agora pra você não cair neles 😉.

Erro 1: = vs ==

### 🐞 Erro 1 — confundir `=` com `==`

Esse é o clássico dos clássicos. `=` atribui, `==` compara.

❌
Errado:

```
if idade = 18:
    print("OK")
```

SyntaxError — Python reclama na hora.

✅
Certo:

```
if idade == 18:
    print("OK")
```

"é igual a 18?" — perfeito.

🧠
Truque mnemônico: "= é caixinha, == é pergunta". Se você quer guardar, é `=`. Se você quer perguntar, é `==`.

Erro 2: esquecer :

### 🐞 Erro 2 — esquecer os dois pontos `:`

O `:` no fim do `if` / `elif` / `else` é obrigatório — é como o Python sabe onde começa o bloco.

❌
Errado:

```
if idade >= 18
    print("OK")
```

SyntaxError: expected ':'

✅
Certo:

```
if idade >= 18:
    print("OK")
```

Os dois pontinhos no fim. Sempre.

📖
Hábito de ouro: quando der erro de sintaxe num `if`, a primeira coisa que você confere é se tem o `:` e se a próxima linha está indentada (4 espaços).

```
elif palpite < secreto:
    print("📉 Muito baixo. Tente mais alto!")
else:
    print("📈 Muito alto. Tente mais baixo!")
```

Desafio para Casa

💡 Dica para fazer sozinho

Crie `descontos.py`. O programa pergunta o valor da compra e aplica desconto por faixa:

• até R$ 50 → sem desconto
• R$ 51 a R$ 200 → 5% de desconto
• R$ 201 a R$ 500 → 10% de desconto
• acima de R$ 500 → 15% de desconto

Passos: 1) leia com `float(input(...))`; 2) use `if/elif/else` pra escolher o desconto; 3) calcule o valor final e mostre uma f-string bonita com 2 casas decimais (`f"{total:.2f}"`).

Lembra do `entrada_evento.py`? A estrutura do `elif` com faixas de número é igualzinha — só muda a regra do negócio.

🚨

PARE! Tente sozinho primeiro. Esse aqui é pra fazer em casa com calma, no seu ritmo. Errar é parte do processo — quem espia antes de tentar perde a maior parte do aprendizado!

👀 Só clique aqui DEPOIS de tentar — Ver código completo ▼

descontos.py Python

```
# pega o valor da compra (com casas decimais)
valor = float(input("Valor da compra: R$ "))

if valor <= 50:
    desconto = 0
elif valor <= 200:
    desconto = 0.05
elif valor <= 500:
    desconto = 0.10
else:
    desconto = 0.15

total = valor * (1 - desconto)
print(f"Desconto aplicado: {desconto*100:.0f}%")
print(f"Total a pagar: R$ {total:.2f}")
```

Valor da compra: R$

🎯
Olha como o elif fica natural: a gente vai descartando faixas de baixo pra cima. Quando o programa chega no `elif valor <= 500`, ele já sabe que o valor é maior que 200 — então cobre exatamente a faixa 201-500. Essa é a beleza do encadeamento.

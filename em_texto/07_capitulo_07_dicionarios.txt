═══════════════════════════════════════════════════════ 2. O QUE É DICIONÁRIO ═══════════════════════════════════════════════════════

📒

Dicionários — chave: valor

Quando lista não basta, dicionário resolve

Pensa na agenda do seu celular 📱

Quando você quer ligar pra Mãe, você não procura "o terceiro número da lista". Você procura pelo nome "Mãe" — e o celular te entrega o número.

É isso que um dicionário faz em Python: você guarda uma chave (tipo "Mãe") e ela aponta pra um valor (o número).

Em Python a sintaxe usa chaves `{ }` e dois pontos:

aluno.py Python

```
# um dicionário: ficha de um aluno
aluno = {
    "nome":  "Kelson",
    "idade": 33,
    "curso": "Python",
}
```

Visualmente o `aluno` é tipo uma ficha cadastral:

aluno

"nome" → "Kelson"

"idade" → 33

"curso" → "Python"

🧠 Sacou a ideia?

A chave (à esquerda) é como a "etiqueta" da gaveta. O valor (à direita) é o que tá guardado lá dentro. E você acessa pela chave, sem se preocupar com posição/índice.

Outras analogias do mundo real:

📇
Carteira de identidade: "Nome → João", "RG → 123…", "Nascimento → 1990".

📱
Agenda telefônica: "Mãe → 9999-1234", "Pai → 9999-5678".

🎫
Carteirinha de aluno: "Curso → Python", "Turma → A", "Matrícula → 042".

Acessar valores

aluno["chave"] — pegar pelo nome da gaveta

Pra pegar um valor, você usa colchetes com a chave entre aspas:

acesso.py Python

```
aluno = {"nome": "Kelson", "idade": 33, "curso": "Python"}

print(aluno["nome"])    # Kelson
print(aluno["idade"])   # 33
print(f"{aluno['nome']} faz {aluno['curso']}!")
```

Run · acesso.py

📌 Lembra como era na lista?

Em lista você acessava por número: `nomes[0]`. Em dicionário você acessa por nome da chave: `aluno["nome"]`. Mais legível, mais "humano". 👍

═══════════════════════════════════════════════════════ 5. ATUALIZAR / ADICIONAR ═══════════════════════════════════════════════════════

✏️

Atualizar e Adicionar valores

aluno["idade"] = 34 — mesma sintaxe pra editar e pra criar novo

Aqui tem uma sacada legal: a sintaxe pra atualizar um valor e pra adicionar uma chave nova é a mesma:

atualizar.py Python

```
aluno = {"nome": "Kelson", "idade": 33, "curso": "Python"}

# ATUALIZAR — a chave 'idade' já existe, então só sobrescreve
aluno["idade"] = 34

# ADICIONAR — a chave 'telefone' não existia, agora existe!
aluno["telefone"] = "99999-1234"

print(aluno)
```

Run · atualizar.py

{'nome': 'Kelson', 'idade': 34, 'curso': 'Python', 'telefone': '99999-1234'}

Visualmente, o dicionário cresce:

aluno (depois)

"nome" → "Kelson"

"idade" → 34 ✏️

"curso" → "Python"

"telefone" → "99999-1234" ✨

💡
Regra simples: se a chave já existir, o Python atualiza. Se não existir, ele cria. Sem stress, sem método especial.

═══════════════════════════════════════════════════════ 7. LISTA DE DICIONÁRIOS ═══════════════════════════════════════════════════════

📋

Lista de Dicionários

Vários cadastros, todos juntinhos numa "prateleira"

Um `aluno` é legal. Mas e se a gente tiver uma turma inteira? A gente coloca vários dicionários dentro de uma lista:

turma.py Python

```
alunos = []   # lista vazia, vai guardar dicts

alunos.append({"nome": "Ana",    "idade": 22, "curso": "Python"})
alunos.append({"nome": "Bia",    "idade": 25, "curso": "Web"})
alunos.append({"nome": "Caio",   "idade": 30, "curso": "Dados"})

# percorrer com for: cada item da lista é um dicionário
for a in alunos:
    print(f"{a['nome']} ({a['idade']}) — {a['curso']}")
```

Run · turma.py

Visualmente é uma prateleira de fichas:

alunos[0]

"nome"→"Ana"

"idade"→22

"curso"→"Python"

alunos[1]

"nome"→"Bia"

"idade"→25

"curso"→"Web"

alunos[2]

"nome"→"Caio"

"idade"→30

"curso"→"Dados"

🎯 Combinando dois mundos

Lista + dicionário é a estrutura mais usada do Python na vida real. Cada item da lista é uma "ficha completa" (dicionário). Você usa o `for` pra percorrer e `["chave"]` pra ler cada campo.

═══════════════════════════════════════════════════════ 8. LISTA VS DICIONÁRIO (VERSUS VISUAL) ═══════════════════════════════════════════════════════

⚔️

Lista vs Dicionário

Quando usar cada um

#### 📋 Lista — acesso por posição

Pense em uma fila ordenada. Você pega pela posição:
`nomes = ["Ana", "Bia", "Caio"]` `nomes[0] # "Ana"` `nomes[2] # "Caio"`
✅ Boa quando a ordem importa.

vs

#### 📒 Dicionário — acesso por chave

Pense em uma ficha. Você pega pelo nome do campo:
`aluno = {"nome": "Ana", "idade": 22}` `aluno["nome"] # "Ana"` `aluno["idade"] # 22`
✅ Boa quando o significado importa.

🤝
Plot twist: os dois juntos são imbatíveis. `alunos = [aluno1, aluno2, aluno3]` — lista ordenada de fichas. É exatamente o que a gente vai usar no Sistema de Cadastro!

═══════════════════════════════════════════════════════ 11. BUGZILLA ═══════════════════════════════════════════════════════

🐛

BugZilla apareceu de novo!

Erros clássicos de quem tá começando com dict

🐛

BugZilla detectou: KeyError

Quando você pede uma chave que não existe

Pediu `aluno["telefon"]` em vez de `aluno["telefone"]`? O Python não advinha. Ele lança um `KeyError` e dá tchau.

erro_keyerror.py Python

```
aluno = {"nome": "Kelson", "idade": 33}

print(aluno["telefone"])    # 💥 KeyError: 'telefone'
```

E tem outro clássico: confundir `{ }` (dict) com `[ ]` (lista). Olha o BugZilla brincando:

erro_chaves.py Python

```
# ❌ ERRADO: usa [ ] querendo dicionário
aluno = ["nome": "Ana"]    # SyntaxError!

# ✅ CERTO: dict usa { }
aluno = {"nome": "Ana"}
```

### 🛡️ Como se proteger

🔍
Confira a grafia da chave. `"nome"` `!=` `"Nome"` `!=` `"nome "`. Python é literal: maiúscula, minúscula e espaço importam.

🛟
Use `.get()` quando você não sabe se a chave existe: `aluno.get("telefone", "não cadastrado")` — devolve o valor se existir, ou o segundo argumento se não existir. Sem erro!

📒
Decora a forma: `{ }` é DICT, `[ ]` é LISTA. Vê os colchetes? São primos, mas brigam.

Faça sozinho · sistema_cadastro.py

Você vai construir um menu interativo que cadastra alunos, guarda numa lista de dicionários, lista todos, busca por nome e mostra um total ao sair. Olha como vai ficar:

==== SISTEMA DE CADASTRO ====

[1] Adicionar aluno

[2] Listar alunos

[3] Buscar por nome

[0] Sair

Escolha uma opção: _

💡 Dica para fazer sozinho

Crie um arquivo `sistema_cadastro.py`. Sua "caixa de ferramentas":

- Comece com uma lista vazia `alunos = []`.
- Use um `while True:` pra ficar mostrando o menu até o usuário escolher sair (opção 0).
- Dentro do loop, mostre o menu com `print()` e leia a opção com `input()`.
- Use `if/elif/else` pra cada opção:

- 1: peça nome, idade (com `int()`) e curso, monte um dict e use `alunos.append({...})`.
- 2: use `for a in alunos` e mostre `a["nome"]`, `a["idade"]`, `a["curso"]`.
- 3: peça um nome, dê outro `for` e compare com `a["nome"] == nome_busca`.
- 0: mostre o total (`len(alunos)`) e use `break` pra sair.

- Não esqueça do `else` pra "opção inválida".

É grandinho, mas você já sabe TUDO que precisa. Vai por partes: primeiro faz o menu rodando. Depois adiciona uma opção por vez. Pequenas vitórias 🏆.

🚨

PARE! Esse aqui é o boss fight do capítulo. Tenta MESMO antes de espiar. Vai dar bug? Vai. Vai precisar reler? Talvez. Mas quando VOCÊ conseguir, você vai sair desse capítulo com gás de programador de verdade. Bora!

👀 Só clique aqui DEPOIS de tentar — Ver código completo ▼

sistema_cadastro.py Python

```
# lista que vai guardar todos os cadastros
alunos = []

while True:
    print("\n==== SISTEMA DE CADASTRO ====")
    print("[1] Adicionar aluno")
    print("[2] Listar alunos")
    print("[3] Buscar por nome")
    print("[0] Sair")
    opcao = input("Escolha uma opção: ")

    if opcao == "1":
        nome  = input("Nome: ")
        idade = int(input("Idade: "))
        curso = input("Curso: ")
        alunos.append({"nome": nome, "idade": idade, "curso": curso})
        print(f"✅ {nome} cadastrado(a) com sucesso!")

    elif opcao == "2":
        if len(alunos) == 0:
            print("Nenhum aluno cadastrado ainda.")
        else:
            print("\n— Lista de alunos —")
            for a in alunos:
                print(f"• {a['nome']} ({a['idade']}) — {a['curso']}")

    elif opcao == "3":
        nome_busca = input("Nome a buscar: ")
        encontrou = False
        for a in alunos:
            if a["nome"] == nome_busca:
                print(f"✅ {a['nome']} — {a['idade']} anos — {a['curso']}")
                encontrou = True
        if not encontrou:
            print(f"❌ Nenhum aluno chamado {nome_busca}.")

    elif opcao == "0":
        print(f"\n👋 Saindo... Total cadastrado: {len(alunos)} aluno(s).")
        break

    else:
        print("❌ Opção inválida. Tenta de novo!")
```

sistema_cadastro_pet.py Python

```
# lista que vai guardar os pets cadastrados 🐾
pets = []

while True:
    print("\n==== CADASTRO DE PETS 🐾 ====")
    print("[1] Adicionar pet")
    print("[2] Listar pets")
    print("[3] Buscar por nome")
    print("[0] Sair")
    opcao = input("Escolha uma opção: ")

    if opcao == "1":
        nome    = input("Nome do pet: ")
        especie = input("Espécie: ")
        idade   = int(input("Idade: "))
        pets.append({"nome": nome, "especie": especie, "idade": idade})
        print(f"✅ {nome} cadastrado(a)! 🐶")

    elif opcao == "2":
        if len(pets) == 0:
            print("Nenhum pet cadastrado ainda.")
        else:
            print("\n— Lista de pets —")
            for p in pets:
                print(f"• {p['nome']} ({p['especie']}, {p['idade']} anos)")

    elif opcao == "3":
        nome_busca = input("Nome a buscar: ")
        encontrou = False
        for p in pets:
            if p["nome"] == nome_busca:
                print(f"✅ {p['nome']} — {p['especie']} — {p['idade']} anos")
                encontrou = True
        if not encontrou:
            print(f"❌ Nenhum pet chamado {nome_busca}.")

    elif opcao == "0":
        print(f"\n👋 Saindo... Total: {len(pets)} pet(s).")
        break

    else:
        print("❌ Opção inválida.")
```

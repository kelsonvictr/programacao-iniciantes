# 🐍 Bootcamp: Programação para Iniciantes

> Material visual e interativo do bootcamp **Programação para Iniciantes** do Programa AI, ministrado pelo **prof. Kelson Almeida**.

🌐 **Acesse online:** [kelsonvictr.github.io/programacao-iniciantes](https://kelsonvictr.github.io/programacao-iniciantes/)

## 📚 O que tem aqui

10 capítulos modulares, cada um em uma página HTML auto-contida com analogias visuais, fluxos animados, exercícios interativos com padrão **olhinho 👀** e o nosso vilão recorrente: o **BugZilla 🐛**.

| # | Capítulo | Tópicos |
|---|---|---|
| 01 | Boas-vindas e Fundamentos | `print` · `input` · primeiro código |
| 02 | Variáveis e Tipos | `str` · `int` · `float` · `bool` · f-strings |
| 03 | Estruturas Condicionais | `if` · `elif` · `else` · operadores |
| 04 | Loops e Listas | `while` · `for` · `range` · listas |
| 05 | Funções | `def` · parâmetros · `return` |
| 06 | Desafios Integradores | 5 mini-sistemas (votação, lanchonete, cinema…) |
| 07 | Dicionários | `dict` · listas de dicionários · sistema de cadastro |
| 08 | Persistência com JSON | `json.dump` · `json.load` |
| 09 | TinyDB | CRUD em arquivo · Query · Tables |
| 10 | Streamlit | Apps web em Python · UI sem HTML/JS |

## 🗂️ Estrutura

```
.
├── index.html          ← hub (lista os 10 capítulos)
├── shared/             ← CSS + JS reutilizáveis
├── capitulos/          ← 10 capítulos, um por pasta
├── context/            ← documentação para IAs (CLAUDE/Copilot/etc)
└── CLAUDE.md           ← contexto raiz para IAs
```

## 🛠️ Stack do material

HTML5, CSS3 e JavaScript puros — **sem build, sem npm, sem framework**. Cada página abre direto no navegador.

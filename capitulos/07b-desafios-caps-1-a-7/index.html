O juramento do olhinho
A regra mais importante do capítulo inteiro

Cada chefão tem duas ajudas escondidas, nessa ordem:

🆘
O empurrãozinho — uma dica extra sem nenhuma linha de código. Use se travar de verdade depois de uns bons minutos tentando.
👀
O olhinho — a solução completa. Esse é o último recurso: só abre depois que seu programa já roda (pra comparar) ou depois de ter tentado MUITO.
🚨
Por que insistimos tanto nisso? Quando você lê uma solução pronta, seu cérebro fala "ah, entendi" — mas entender de ler e saber fazer são coisas MUITO diferentes. O aprendizado mora no tempo em que você fica travado, tentando. O olhinho existe pra proteger esse tempo, não pra pular ele.

"Eu juro tentar sozinho(a) primeiro,
errar sem vergonha, ler os erros com calma,
e só abrir o olhinho 👀 depois de dar o meu máximo."

Playlist AI

Um app de música raiz: você cadastra suas músicas favoritas e, no final, ele mostra a playlist inteira com o tempo total de som. Tipo um Spotify de terminal. 😄

📜 As regras do chefão:

O programa fica pedindo músicas até você digitar "sair".
Cada música pergunta 3 coisas: título, artista e duração em minutos (número inteiro).
Cada música vira um dicionário com as chaves "titulo", "artista" e "duracao" — e entra numa lista.
Ao sair, mostre a playlist completa: uma linha por música, com título, artista e duração (capricha na f-string!).
Feche com o total: quantas músicas tem na playlist e a soma de todos os minutos.

💡 Dica para fazer sozinho

Esse chefão é primo de dois programas que você já fez: o adicionar_nomes.py (cap 4.5) e o cadastro_dicionario.py (cap 07). A espinha é a mesma: lista vazia → while True → input → if ... == "sair": break → append.

A diferença: em vez de dar append num texto solto, você monta um dicionário com os 3 dados e dá append nele. No final, um for percorre a lista imprimindo cada ficha, e um acumulador (lembra dele?) vai somando as durações.

⚠️
Pegadinha clássica: cheque o "sair" logo depois de pedir o título — antes de perguntar artista e duração. Senão o programa pede artista da música "sair". 😅
🚨

playlist = []

print("==== 🎧 PLAYLIST AI ====")

while True:
    titulo = input("Música (ou 'sair' pra fechar): ")
    if titulo == "sair":
        break
    artista = input("Artista: ")
    duracao = int(input("Duração em minutos: "))
    playlist.append({"titulo": titulo, "artista": artista, "duracao": duracao})
    print(f"✅ {titulo} entrou na playlist!")

print("\n==== 🎶 SUA PLAYLIST ====")
total = 0
for musica in playlist:
    print(f"• {musica['titulo']} — {musica['artista']} ({musica['duracao']} min)")
    total += musica["duracao"]

print(f"\n{len(playlist)} música(s) · {total} minutos de som 🔊")

Mercadinho AI

Agora você é o caixa: o mercadinho já tem uma prateleira de produtos (lista de dicionários pronta no código) e o cliente vai falando o que quer levar. Você busca o produto, soma no carrinho e, no final, imprime o cupom — com desconto se a compra for grande. 🧾

📜 As regras do chefão:

O programa começa com a prateleira pronta no código: uma lista com 5 dicionários, cada um com "nome" e "preco" (invente os produtos e preços que quiser!).
Crie uma função mostrar_cardapio() que imprime todos os produtos com preço no formato R$ 25.50 — e chame ela logo no início.
Depois, um loop: o cliente digita o nome do produto. Se digitar "fim", fecha a conta. Se digitar "cardapio", mostre a prateleira de novo (reusando a função — é pra isso que ela existe!).
Pra qualquer outro texto: procure o produto na lista. Achou? Soma o preço no total e mostra o parcial. Não achou? "❌ Hoje não temos esse produto."
No final, imprima o cupom com o total. Se a compra deu R$ 50 ou mais, aplique 10% de desconto e mostre o novo total. 🎉

💡 Dica para fazer sozinho

A busca é o coração desse chefão — e você já fez ela no sistema_cadastro.py (cap 07, opção "buscar"): um for percorrendo a lista, um if comparando produto["nome"] com o que o cliente digitou, e uma variável encontrou = False que vira True quando acha (a famosa flag).

A função mostrar_cardapio() é do tipo mais simples que existe (cap 05): sem parâmetro, sem return — só um for com print dentro. E pra mostrar preço bonito com 2 casas, lembra da missão da média (cap 04)? f"R$ {preco:.2f}".

O desconto de 10%: multiplicar por 0.90 é o mesmo que tirar 10%.

⚠️
Pegadinha: teste o "fim" e o "cardapio" antes de sair procurando na prateleira — senão o programa vai dizer que "não temos o produto fim". 😄

produtos = [
    {"nome": "arroz",    "preco": 25.50},
    {"nome": "feijao",   "preco": 9.90},
    {"nome": "cafe",     "preco": 18.00},
    {"nome": "leite",    "preco": 6.50},
    {"nome": "biscoito", "preco": 4.75},
]

def mostrar_cardapio():
    print("\n==== 🛒 MERCADINHO AI ====")
    for produto in produtos:
        print(f"• {produto['nome']} — R$ {produto['preco']:.2f}")

mostrar_cardapio()
total = 0

while True:
    escolha = input("\nProduto (ou 'cardapio' / 'fim'): ")
    if escolha == "fim":
        break
    if escolha == "cardapio":
        mostrar_cardapio()
    else:
        encontrou = False
        for produto in produtos:
            if produto["nome"] == escolha:
                total += produto["preco"]
                print(f"🧺 {escolha} no carrinho! Parcial: R$ {total:.2f}")
                encontrou = True
        if not encontrou:
            print("❌ Hoje não temos esse produto.")

print("\n==== 🧾 CUPOM FISCAL ====")
print(f"Total da compra: R$ {total:.2f}")
if total >= 50:
    total = total * 0.90
    print(f"🎉 Compra acima de R$ 50! Com 10% de desconto: R$ {total:.2f}")
print("Volte sempre! 👋")

Banco AI — o chefão final

O maior programa que você já escreveu: um banco com menu completo onde dá pra criar conta, depositar, sacar e ver todas as contas. Com direito a validação de saldo — ninguém saca dinheiro que não tem! 💸

📜 As regras do chefão:

As contas vivem numa lista de dicionários, cada uma com "nome" e "saldo" (começando em 0.0).
Menu num while True: [1] criar conta · [2] depositar · [3] sacar · [4] ver contas · [0] sair.
Crie uma função buscar_conta(nome) que procura a conta pelo nome e devolve (return) o dicionário quando acha. Você vai usar ela nas opções 1, 2 e 3 — três usos, uma função!
Criar conta: se o nome já existe, avise. Senão, entra na lista com saldo zero.
Depositar: busca a conta; se não existe, avisa. Se existe, pergunta o valor (float()!) e soma no saldo do dicionário.
Sacar: igual ao depósito, mas com uma validação a mais — se o valor for maior que o saldo: "🚫 Saldo insuficiente!".
Ver contas: lista todas com o saldo formatado (:.2f). Sem contas ainda? Avise também.
🆕 Um tempero novo (o único do capítulo): None

E se buscar_conta("Zé") não achar o Zé? A função devolve None — a palavra do Python pra "nada" (é o que o .get() do cap 07 devolve quando a chave não existe, lembra?). Aí quem chamou testa: if conta == None: → conta não existe, avisa o cliente.

Ou seja: sua função devolve a ficha da conta OU "nada" — e o resto do programa decide o que fazer com cada caso. 🧠

💡 Dica para fazer sozinho

Esse chefão é o sistema_cadastro.py do cap 07 turbinado: a mesma espinha (lista + while True + menu if/elif/else), só que agora as opções mexem nos dados — depositar e sacar atualizam o conta["saldo"], do jeito que você aprendeu no atualizar_dados_aluno.py.

Comece pela função buscar_conta(nome): um for na lista, um if comparando o nome, e return conta quando achar. Se o for terminar sem achar ninguém, return None na última linha da função.

Depois monte o menu opção por opção, testando cada uma antes de ir pra próxima: primeiro só criar+ver, roda e testa. Depois depositar, roda e testa. Por último sacar. Programador de verdade constrói assim, em fatias. 🍰

⚠️
Pegadinhas: o BugZilla logo ali em cima já te contou a do menu (compare opcao == "1" com aspas!). E o valor do depósito/saque precisa de float(), senão o += quebra tentando somar texto com número.
🚨

contas = []

def buscar_conta(nome):
    for conta in contas:
        if conta["nome"] == nome:
            return conta
    return None

while True:
    print("\n==== 🏦 BANCO AI ====")
    print("[1] Criar conta  [2] Depositar  [3] Sacar")
    print("[4] Ver contas   [0] Sair")
    opcao = input("Escolha uma opção: ")

    if opcao == "1":
        nome = input("Nome do cliente: ")
        if buscar_conta(nome) != None:
            print("❌ Esse cliente já tem conta!")
        else:
            contas.append({"nome": nome, "saldo": 0.0})
            print(f"✅ Conta de {nome} criada!")

    elif opcao == "2":
        nome = input("Conta de quem? ")
        conta = buscar_conta(nome)
        if conta == None:
            print("❌ Conta não encontrada.")
        else:
            valor = float(input("Valor do depósito: R$ "))
            conta["saldo"] += valor
            print(f"💰 Novo saldo de {nome}: R$ {conta['saldo']:.2f}")

    elif opcao == "3":
        nome = input("Conta de quem? ")
        conta = buscar_conta(nome)
        if conta == None:
            print("❌ Conta não encontrada.")
        else:
            valor = float(input("Valor do saque: R$ "))
            if valor > conta["saldo"]:
                print("🚫 Saldo insuficiente!")
            else:
                conta["saldo"] -= valor
                print(f"💸 Saque feito! Saldo: R$ {conta['saldo']:.2f}")

    elif opcao == "4":
        if len(contas) == 0:
            print("Nenhuma conta ainda.")
        else:
            for conta in contas:
                print(f"• {conta['nome']} — R$ {conta['saldo']:.2f}")

    elif opcao == "0":
        print("👋 Banco AI fechado por hoje!")
        break

    else:
        print("❌ Opção inválida.")

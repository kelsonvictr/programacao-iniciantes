🐍 Um projeto só pra esses 30 desafios

Cada desafio será um arquivo .py separado dentro de UM ÚNICO projeto chamado desafio_caps_1_2_3. Bora montar agora pra você não precisar pensar nisso de novo:

Abra o PyCharm. Na tela inicial, clique em New Project (ou no menu File → New Project… se já estiver com outro projeto aberto).
No campo Location, escolha onde salvar e dê o nome desafio_caps_1_2_3 ao final do caminho. Ex.: ~/PycharmProjects/desafio_caps_1_2_3.
Em Interpreter type, deixe a opção padrão recomendada (Project venv com Python 3.10 ou superior). Se não tiver Python, clique em Add Interpreter e o próprio PyCharm baixa pra você.
Pode desmarcar a opção Create a welcome script / main.py — vamos criar nossos próprios arquivos.
Clique em Create. Aguarde o PyCharm preparar o ambiente (vai aparecer uma barrinha lá embaixo). ☕
Dica: pra criar cada desafio, clique com o botão direito na pasta do projeto → New → Python File → digite o nome (ex.: ola_pessoal.py) → Enter. ✅
Pra rodar: com o arquivo aberto, clique no triângulo verde ▶ no canto superior direito (ou botão direito → Run 'nome_do_arquivo').
⚠️
Não esquece: nomes de arquivo Python sempre em minusculo_com_underline.py. Sem espaços, sem acentos, sem maiúsculas — esse é o estilo oficial da galera Python (chamado snake_case) 🐍.
💡
Por que um projeto só? Assim você acumula os 30 arquivos numa pastinha só, fica fácil revisar depois e o PyCharm já fica configurado (interpreter, virtualenv) — você não perde tempo abrindo várias janelas.

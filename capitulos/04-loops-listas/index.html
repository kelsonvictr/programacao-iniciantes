while — fica fazendo enquanto…
A primeira estrutura de repetição
Pensa numa torneira pingando

Enquanto a torneira estiver aberta, ela pinga. Você fecha → para de pingar. Enquanto seu celular tem bateria, ele liga. Bateria acabou → desliga. Esse "enquanto" é literalmente o while em Python.

A estrutura é assim:

    ...
🎬 Ele em ação — contagem de 1 a 5

➡️
for — passa em cada um da fila
Quando você sabe quantas vezes vai repetir
Pensa num professor fazendo chamada

Ele tem uma lista de alunos e vai um por um: "Ana?", "João?", "Davi?"… Não precisa contar nada — ele só percorre a fila. É isso que o for faz: percorre uma sequência, item por item.

exemplo_for.py Python
1
2
for item in sequencia:
    print(item)

🔁 while

  • "Enquanto algo for verdade…"
  • Você controla o contador na mão
  • Pode rodar 0 ou ∞ vezes
  • Cuidado com loop infinito 🌀

➡️ for

  • "Pra cada item da sequência…"
  • O Python controla pra você
  • Roda exatamente N vezes (tamanho da sequência)
  • Mais seguro e mais comum no dia a dia
💡
Regra prática: se você sabe quantas vezes vai repetir, use for. Se depende de uma condição que muda (tipo "enquanto o usuário não digitar sair"), use while.
📏
range() — uma régua de números
O parceiro favorito do for
Pensa numa régua de escola

A régua tem números marcadinhos: 1, 2, 3, 4, 5… O range(1, 6) é literalmente isso — uma régua que vai de 1 até 5. Sim, até 5, não até 6!

⚠️
O detalhe que pega todo mundo: em range(start, stop), o número stop NÃO entra na sequência. Ele é o "limite" — chegou nele, para.

range(1, 6) gera:

1
2
3
4
5
6
✅ entram: 1, 2, 3, 4, 5  ·  ❌ NÃO entra: 6 (é o limite!)
exemplo_range.py Python
1
2
3
4
# for + range = combo perfeito
for numero in range(1, 6):
    print(numero)
# imprime: 1, 2, 3, 4, 5
🎯
Atalho: range(5) (só com um número) também funciona — ele vai de 0 até 4 (sempre começa em 0 quando você não diz o início).

BugZilla apareceu de novo!
Os erros clássicos de loop
🐛
Dois pesadelos do iniciante com loops
A gente sofre — depois aprende. Todo mundo passa por aqui.

Erro 1: esquecer os dois pontos : no fim do while ou for.

errado.py erro 
while contador <= 5   # ❌ faltou os : no final
    print(contador)
    contador += 1

O Python reclama com algo tipo: SyntaxError: expected ':'. Bom, é exatamente isso — esqueceu os dois pontinhos.

Erro 2: loop infinito 🌀 — o famoso "esqueci de incrementar".

infinito.py perigo 
contador = 1
while contador <= 5:
    print(contador)
    # 😱 esqueceu de fazer contador += 1
    # resultado: imprime "1" pra sempre 🌀🌀🌀

Se isso acontecer com você no PyCharm, aperta o botão Stop ⏹ (quadradinho vermelho) pra matar o programa. Fica tranquilo, computador não explode 😄.

👀 Como CORRIGIR cada um — clique pra ver ▼
corrigido.py Python
1
2
3
4
contador = 1
while contador <= 5:    # ✅ tem os dois pontos
    print(contador)
    contador += 1             # ✅ incrementa, sempre
📖
Hábito de ouro: sempre que escrever while, já escreva o incremento na hora. Tipo um casamento — não deixe para depois.
📋 Parte 2 — Listas

Guardando várias coisas em uma caixinha só

Até agora cada variável guardava uma coisa. E se você quiser guardar todos os alunos da turma? Bora conhecer as listas.

📋
Listas — uma prateleira numerada
Vários valores, uma só variável
Pensa numa prateleira numerada

Cada posição da prateleira tem um número fixo: 0, 1, 2, 3… (sim, começa em zero, programador é assim 😅). Em cada posição você guarda uma coisa. Pra pegar uma coisa específica, você aponta para o número da posição.

# minha primeira lista
alunos = ["Ana", "João", "Davi", "Maria", "Lia"]

print(alunos[0])   # Ana   — primeira posição
print(alunos[2])   # Davi  — terceira posição

Visualmente:

⚠️
Cuidado: índice começa em 0! O "primeiro" da lista é alunos[0], não alunos[1]. É contraintuitivo, mas é assim em quase toda linguagem de programação.

Desafio Individual — Climax do capítulo
Faça sozinho · lista_interativa.py
💡 Dica para fazer sozinho

Crie lista_interativa.py. Esse é o exercício cumulativo do capítulo — você vai juntar tudo: while, input, lista, append, for. 🤯

Comportamento esperado:

  1. Comece com uma lista vazia: nomes = [].
  2. Use while True: pra repetir até o usuário digitar "sair".
  3. A cada volta, peça um nome com input().
  4. Se o nome for "sair", use break pra parar o loop.
  5. Senão, append o nome na lista.
  6. Quando sair do loop, mostre a lista final com um for.

🆕 Conceito novo: break faz o loop parar imediatamente, mesmo que a condição ainda fosse True.

🚨
PARE! Esse é o desafio mais legal do capítulo. Tenta de verdade — pode dar erro, pode ficar 10 minutos quebrando a cabeça, e tá ótimo. É aí que o cérebro aprende. 💪

# lista vazia pra começar
nomes = []

while True:
    nome = input("Digite um nome (ou 'sair' pra terminar): ")
    if nome == "sair":
        break             # 👋 sai do while
    nomes.append(nome)

print("\n--- Lista final ---")
for n in nomes:
    print(f"• {n}")

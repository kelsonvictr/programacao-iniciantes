O que é o Super Desafio

E como todo bom jogo, primeiro tem um tutorial (a gente derrota o chefão juntos, passo a passo) e depois um segundo chefão parecido pra você encarar sozinho. Se fez o primeiro, faz o segundo. 💪

Vamos guardar os dois programas no MESMO projeto, chamado super_desafio. O guiado vira cinema_ai.py e o seu vira parque_ai.py.

Abra o PyCharm → New Project (ou File → New Project…).
No Location, dê o nome super_desafio ao fim do caminho. Ex.: ~/PycharmProjects/super_desafio.
Deixe o interpretador padrão (Project venv, Python 3.10+). Sem Python? Clique Add Interpreter que o PyCharm baixa.
Pode desmarcar o welcome script / main.py. Clique Create. ☕
Botão direito na pasta → New → Python File → cinema_ai.py → Enter. ✅
Rodar: triângulo verde ▶ no canto superior direito (ou botão direito → Run).
⚠️
Nome de arquivo Python sempre em minusculo_com_underline.py — sem espaços, sem acentos, sem maiúsculas (estilo snake_case 🐍).

🧠
A ordem importa! O Python testa de cima pra baixo e para no primeiro verdadeiro. Por isso idade < 5 vem antes de idade <= 12 — uma criança de 3 anos cairia nas duas, mas a gente quer que ela pegue o "colo".

Etapa 3 — Benefício com and / or
combinando condições de verdade
🎯
Construindo junto — Etapa 3
meia-entrada: estudante OU quarta

A regra é: se a categoria é "Inteira" E (a pessoa é estudante OU é quarta-feira) → vira meia-entrada, preço cai pela metade. Lê em voz alta — é quase português:

# 3) Benefício: meia pra estudante OU na quarta-feira
if categoria == "Inteira" and (estudante == "s" or dia == "quarta"):
    categoria = "Meia-entrada"
    preco = preco / 2
🔗
Os parênteses são de propósito. Eles agrupam o "estudante OU quarta" como uma pergunta só. Em português: "é inteira E (é estudante OU é quarta)?". Sem os parênteses, o Python poderia entender outra coisa.
✨
preco = preco / 2 pega o valor atual da caixinha, divide por 2 e guarda de volta na mesma caixinha. R$ 30 vira R$ 15.

BugZilla ataca o Super Desafio
o erro nº1 de quem mistura tudo
🐛
"Roda no PyCharm e explode!"
esquecer o int() na idade

O erro campeão nesse tipo de programa: pegar a idade com input() e esquecer o int(). Aí a idade fica como texto, e o Python não deixa comparar texto com número.

❌
Errado: 
idade = input("Idade: ")
if idade >= 60:
    ...
TypeError — não dá pra comparar "60" (texto) com 60 (número).
✅
Certo: 
idade = int(input("Idade: "))
if idade >= 60:
    ...
Agora idade é número de verdade. A comparação funciona.
🧠
Regra de bolso: se você vai comparar com número ou fazer conta, converte na hora de pegar — int() pra inteiro, float() pra valor com centavos.

💡 O que fazer (passo a passo)

Crie o arquivo parque_ai.py e siga o mesmo caminho do Cinema AI:

1) Cabeçalho com print() e o cadastro: nome (texto), idade com int(), altura com float() e socio (texto "s"/"n").
2) if/elif/else pra definir categoria e preco pela faixa de idade (use as 4 faixas das regras).
3) if socio == "s": → preco = preco * 0.8.
4) Mostre o resumo com f-string e decida a montanha-russa com if idade >= 12 and altura >= 1.40:.
5) Peça o pagamento com float() e mostre o troco com if/else (igualzinho ao Cinema).

🎯
Dica de ouro: abra o seu cinema_ai.py do lado. A espinha é idêntica — você só troca os valores, os textos e adiciona a regrinha da altura. Não está começando do zero!

# 1) Cadastro do visitante
nome   = input("Seu nome: ")
idade  = int(input("Sua idade: "))
altura = float(input("Sua altura em metros (ex: 1.70): "))
socio  = input("É sócio do parque? (s/n): ")

# 2) Preço base pela faixa de idade
if idade < 6:
    categoria = "Criança (grátis)"
    preco = 0.0
elif idade <= 12:
    categoria = "Infantil"
    preco = 40.0
elif idade >= 60:
    categoria = "Melhor idade"
    preco = 35.0
else:
    categoria = "Adulto"
    preco = 80.0

# 3) Sócio ganha 20% de desconto
if socio == "s":
    preco = preco * 0.8

# 4) Resumo + regra da montanha-russa
print("---------------------------------")
print(f"Visitante: {nome}")
print(f"Categoria: {categoria}")
print(f"Valor da entrada: R$ {preco:.2f}")

if idade >= 12 and altura >= 1.40:
    print("🎢 Liberado para a MONTANHA-RUSSA!")
else:
    print("🎠 Hoje você curte o carrossel (regra de segurança).")

# 5) Pagamento e troco
pago = float(input("Quanto você vai pagar? R$ "))
if pago < preco:
    print(f"❌ Faltou R$ {preco - pago:.2f}. Pagamento insuficiente.")
else:
    print(f"✅ Troco: R$ {pago - preco:.2f}")
    print(f"🎉 Bom passeio, {nome}!")
